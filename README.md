# 📄 Resume / CV Website

A clean and professional **Resume / CV Website** built using **HTML5**. This project showcases my personal profile, education, skills, projects, and contact information in a simple and user-friendly layout.

## 🌐 Live Demo

👉 https://singhwatsalraj-arch.github.io/RESUME/



## ✨ Features

- 👤 Profile Photo
- 📝 Career Objective
- 🎓 Education Details
- 💻 Technical Skills
- 🚀 Projects Section
- 📧 Contact Information
- 🔗 GitHub  Links
- 🌍 Languages
- 🎯 Hobbies
- 📄 Declaration
